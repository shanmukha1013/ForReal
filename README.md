# ForReal V2

WE DON'T TALK SHIT.

ForReal is a next-generation social discussion platform built around authentic conversations.

## Architecture
- **Frontend:** React 19, Vite, Tailwind CSS, Zustand, React Query
- **Backend:** Node.js, Express.js, MongoDB Atlas, Socket.IO
- **Design Philosophy:** Premium, Professional, Bold, Elegant, Minimal

## Getting Started

1. Clone the repository.
2. Setup environment variables based on `.env.example`.
3. `npm run dev` in `client` to start the frontend.
4. `npm run dev` in `server` to start the backend.
